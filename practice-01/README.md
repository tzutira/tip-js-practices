## 5. Задание 2. Типы и преобразования

| Выражение | Ожидание до запуска | Фактическое значение | Тип результата | Объяснение |
|---|---|---|---|---|
| `"8" + 2` | `"82"`, `string` | `"82"` | `string` | `+` со строкой объединяет значения в текст. |
| `"8" - 2` | `6`, `number` | `6` | `number` | `-` выполняет числовое преобразование и вычитание. |
| `Number("8") + 2` | `10`, `number` | `10` | `number` | После `Number()` складываются два числа. |
| `"12" > "3"` | `false`, `boolean` | `false` | `boolean` | При сравнении строк первый символ `"1"` меньше `"3"`. |
| `12 === "12"` | `false`, `boolean` | `false` | `boolean` | `===` не приводит строку к числу. |
| `Number("")` | `0`, `number` | `0` | `number` | Для пустой строки `Number()` даёт ноль. |
| `Number("text")` | `NaN`, `number` | `NaN` | `number` | Нечисловой текст даёт `NaN` числового типа. |
| `Boolean("false")` | `true`, `boolean` | `true` | `boolean` | Важна непустота строки, а не значение слова. |
| `typeof null` | `"object"`, `string` | `"object"` | `string` | Историческая особенность; ответ `typeof` — строка. |
| `typeof NaN` | `"number"`, `string` | `"number"` | `string` | `typeof` выдаёт название числового типа строкой. |
