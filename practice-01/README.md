## 5. Задание 2. Типы и преобразования

| Выражение | Ожидание до запуска | Фактическое значение | Тип результата | Объяснение |
|---|---|---|---|---|
| `"8" + 2` | `"82"`, `string` | `"82"` | `string` | `+` со строкой объединяет значения в текст. |
| `"8" - 2` | `6`, `number` | `6` | `number` | `-` выполняет числовое преобразование и вычитание. |

| `Number("")` | `0`, `number` | `0` | `number` | Для пустой строки `Number()` даёт ноль. |
| `Number("text")` | `NaN`, `number` | `NaN` | `number` | Нечисловой текст даёт `NaN` числового типа. |

## 7. Задание 4. План выполнения задач

Данные варианта 4:

```text
totalTasks = 20
completedTasks = 11
dailyLimit = 6
```

Результат:

```text
Осталось задач: 9
День 1: выполнено 6, осталось 3
День 2: выполнено 3, осталось 0
Потребуется дней: 2
```

### Проверки

| `totalTasks` | `completedTasks` | `dailyLimit` | Ожидаемый результат | Фактический результат | Итог |
|---|---|---|---|---|---|
| `12` | `5` | `3` | 3 дня; выполнено по дням: 3, 3, 1 | 3 дня; выполнено: 3, 3, 1 | Пройдено |
| `10` | `4` | `3` | 2 дня, по 3 задачи | 2 дня, по 3 задачи | Пройдено |
| `5` | `3` | `10` | 1 день, выполнено 2 задачи | 1 день, выполнено 2 задачи | Пройдено |
| `5` | `5` | `2` | 0 дней; цикл не выполняется | Все задачи уже выполнены; потребуется дней: 0 | Пройдено |
| `0` | `0` | `2` | 0 дней; цикл не выполняется | Все задачи уже выполнены; потребуется дней: 0 | Пройдено |
| `5` | `2` | `0` | Ошибка: нулевой дневной лимит | Ошибка: значения вне допустимого диапазона | Пройдено |
| `5` | `2` | `1.5` | Ошибка: дробной дневной нормы быть не должно | Ошибка: все значения должны быть целыми числами | Пройдено |
| `5` | `6` | `2` | Ошибка: выполнено больше общего количества | Ошибка: значения вне допустимого диапазона | Пройдено |
| `5` | `2` | `"2"` | Ошибка: дневной лимит задан строкой | Ошибка: все значения должны быть целыми числами | Пройдено |
| `5` | `2` | `1001` | Ошибка: дневной лимит больше 1000 | Ошибка: значения вне допустимого диапазона | Пройдено |
| `20` | `11` | `6` | 2 дня; сначала 6 задач, затем 3 | 2 дня; выполнено: 6, 3 | Пройдено |

План строится циклом `while`: каждый проход соответствует одному дню. `Math.min()` выбирает меньшее из дневного лимита и остатка, поэтому количество оставшихся задач не становится отрицательным.

Все данные проверяются до цикла, включая дневной лимит при нулевом остатке. При ошибке план не рассчитывается. При допустимом лимите остаток уменьшается на каждом шаге, поэтому цикл завершается.
